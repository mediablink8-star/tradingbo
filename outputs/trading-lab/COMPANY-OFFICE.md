# Agent company office

Refresh the local dashboard. The company office is at the top; Open company window expands it into a large overlay. Click a workstation or one of the six agent buttons to inspect the latest report. Escape or Close window returns to the dashboard.

Live paper team displays the latest recorded live_agent_report events and current observer counts. Unconfigured AI is explicitly shown as waiting. Historical initial reports do not animate as new activity. Newly received reports trigger visual handoff effects. Experiment team follows the bounded experiment observed in this page and labels scripted runs as no AI. Performance reviewer is deterministic accounting, not an extra model.

Office demo shows illustrative sample handoffs without starting a trial, calling a model, accessing credentials or requesting wallet actions. Pause animation only pauses the visualization. Reduced-motion preferences start it paused. The office does not change strategy settings or trade anything.

The office uses an isolated sandboxed frame. It receives only a subset of agent reports and observer metrics, never API keys or wallet details. Untrusted report text is rendered as text. The page can show stale state when observer updates stop; the office labels that condition.
