# Operations dashboard

Overview contains a nine-item setup checklist, the strategy scoreboard, and saved alert history. Research contains the decision journal, with exact-mint and category filters, stable pagination, and export of the displayed page. All rendered evidence uses text content, not injected HTML.

The journal includes reported rationales, screening reasons, explicit unanimous team verdicts and vetoing roles, fills and rejected orders. New completed paper trades record entry time and trade-level P&L after declared entry/exit network assumptions. AI costs are not allocated to individual trades; account returns include recorded AI charges. Old records without trade-level P&L are left as originally recorded. Rejected tokens do not receive invented retrospective outcomes.

A fixed momentum account starts prospectively at $100, uses the same screens, delays, quote adapter, exits and risk limits, and makes no model calls. The existing AI and baseline accounts retain their balances, positions and history. A dated comparison start records all three starting equities. Scoreboard period P&L and returns use that common start time; lifetime drawdown, charges and trade counts are labeled. Because starting balances and previous positions can differ, this is a diagnostic comparison, not a randomized demonstration of AI value. The fixed-rule account still requires a quote key and fresh token-risk evidence. No artificial trading history is filled in.

The local server checks worker, feed, freshness, risk and unresolved billing every ten seconds and persists incident openings and recovery. Repeated failures share one active incident; acknowledged incidents remain active until recovered. New failures after recovery create a new incident. Browser polling also detects server unavailability. Optional desktop notifications require user permission and an open dashboard; no email, external messaging or cloud monitor is configured. A stopped server cannot persist incidents until it returns. Desktop permission behavior was not exercised during verification.

Office workers display recent tasks, report age and intended handoff destination. Real model calls emit a persisted working event before invocation. The performance reviewer shows deterministic account calculations separately from model reports. CEO supervision includes today's UTC call count, current eligible candidates and active incidents. Animation remains illustrative and cannot override risk gates.

Verification: 91 backend tests passed, including incident deduplication/recovery/acknowledgement, journal pagination/token filtering, persisted disagreements and fixed-rule entries without model calls. Real Chrome checks confirmed all navigation pages, nine checklist rows, three comparison rows, journal entries, no duplicate IDs and no runtime exceptions. Desktop overview and office previews were inspected. No model or Jupiter key is configured and no real trades were submitted. This update does not add cloud hosting, backups or unattended real-wallet execution.
